# Customer Trends Data Analysis (SQL, Python & Power BI)

## Overview
This end-to-end data analytics project analyzes customer shopping data to uncover purchasing patterns, customer behavior trends, and actionable business insights. Using Python for exploratory data analysis (EDA) and data cleaning, SQL for data aggregation and query analysis, and Power BI for interactive dashboard creation, this project transforms complex raw data into business-driven solutions.

---

## Tech Stack & Tools
* *Data Processing & EDA:* Python (Pandas, NumPy).
* *Database & Querying:* MySQL / SQL.
* *Visualization & Dashboards:* Power BI (DAX, Interactive Dashboards).
* *Spreadsheets:* Microsoft Excel.

---

## Key Features & Project Workflow

1. *Data Cleaning & Preparation:*
   * Cleaned and preprocessed customer dataset using Python (Pandas, NumPy) to fix missing values and data inconsistencies.
   * Prepared structured datasets ready for relational database loading and analytics.

2. *Exploratory Data Analysis (EDA) & SQL Queries:*
   * Wrote business-focused SQL queries utilizing aggregations, filtering, joins, and CTEs.
   * Analyzed key business metrics such as total revenue, purchasing frequency, customer demographics, and product performance.

3. *Interactive Power BI Dashboard:*
   * Built custom *DAX measures* and calculated columns to model key performance indicators (KPIs).
   * Designed interactive visual reports with dynamic filters/slicers to facilitate data-driven decision-making.
